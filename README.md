# Education in Motion

Адаптивний двомовний особистий блог українською та англійською. Працює як звичайний статичний сайт: без збірки, бази даних і спеціального сервера. Одна й та сама тека підходить для GitHub Pages, Netlify, Vercel, Cloudflare Pages або власного хостингу.

## Запуск

Завантажте всі п’ять файлів (`index.html`, `styles.css`, `app.js`, `posts.json`, `posts-en.json`) до однієї теки на хостингу. Відкрийте `index.html` через статичний вебсервер або сервіс хостингу. Для локального перегляду можна скористатися будь-яким простим локальним сервером: браузери зазвичай блокують завантаження JSON-файлів, якщо відкрити HTML безпосередньо як файл.

## Як додати матеріал

Відкрийте `posts.json` і додайте новий об’єкт у масив дописів. Поля:

- `id` — унікальне коротке посилання латиницею;
- `title`, `category`, `date` (формат `YYYY-MM-DD`), `readTime`, `excerpt`;
- `symbol` — один символ для обкладинки;
- `tone` — один із класів `tone-green`, `tone-lilac`, `tone-blue`, `tone-pink`, `tone-yellow`;
- `featured` — необов’язкове `true`, щоб показати матеріал у великому блоці;
- `content` — список блоків статті: абзац (`p`), заголовок (`h2`), список (`ul`), джерела (`sources`), фото (`image`) або відео (`video`). Для фото вказуйте `src`, `alt`, підпис і атрибуцію; для відео — `videoId`, `title`, підпис та посилання на джерело.

Збережіть файл і опублікуйте зміни — сайт підхопить допис автоматично. Теми фільтрів створюються з категорій у файлі. У HTML можна змінити назву блогу, опис і контакт автора (`hello@example.com`).

Для англомовної версії додайте переклад з таким самим `id` у `posts-en.json` (назву, категорію, час читання, опис і блоки `content`). Не змінюйте ідентифікатор між мовними версіями — він пов’язує переклади. Перемикач мови розташований у шапці сайту.

На картці кожної статті є кнопка поширення, яка відкриває варіанти; у вікні статті доступні системне поширення, копіювання постійного посилання та швидкі посилання для Telegram, Facebook, LinkedIn, WhatsApp і електронної пошти. Адреса містить ID статті в hash-фрагменті; сайт відкриває її після завантаження дописів. Системне поширення працює у браузерах, що підтримують Web Share API; копіювання має запасний варіант для інших браузерів.

Фотографії та відео завантажуються із зовнішніх джерел, тож для їх перегляду потрібен інтернет. Для фото з Wikimedia Commons зберігайте посилання на автора та ліцензію. Відео вставляються через YouTube у режимі privacy-enhanced.

У блозі є редакційна добірка про психологічну підтримку з посиланнями на ВООЗ, МОЗ України, портал «Ти як?» та УВКБ ООН. Контакти й умови послуг можуть змінюватися: перед зверненням звіряйте їх на сторінці відповідної організації. Матеріали блогу мають інформаційний характер і не замінюють професійну допомогу.

## Підключення до різних платформ

Це звичайні HTML, CSS, JavaScript і JSON файли, тож їх можна розміщувати на статичному хостингу, у власному домені або вставити як сторінку в систему, що приймає HTML. Для конструктора сайтів без доступу до файлової теки перенесіть розмітку та стилі в його HTML/CSS блоки, а дописи з `posts.json` — у вбудований CMS/колекцію. Для редакційної команди цей самий вигляд можна під’єднати до Headless CMS, замінивши завантаження JSON у `app.js` на її API.

Шрифти завантажуються з Google Fonts; якщо потрібен повністю автономний сайт, приберіть посилання на шрифти в `index.html` — буде використано системні запасні шрифти.
